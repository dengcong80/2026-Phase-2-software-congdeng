# Auckland Quest

## Project Overview

Project Name

Auckland Quest – Discover Auckland Like a Local


Theme

Gamification

---

## Project Goal

Build a gamified community platform that encourages people to explore Auckland,
learn local culture, contribute to the community and earn rewards.

The project must combine

- Real-world Exploration
- Community Contribution
- Gamification

The application is NOT a travel booking system.

The application is NOT a social media clone.

The application is NOT an online game.

It is a community exploration platform.

---

## Core Features

Users can

- Register
- Login
- Browse Quests
- Complete Quests
- Upload Photos
- Write Tips
- Create Community Quests
- Like Posts
- Comment
- Earn XP
- Unlock Badges
- Level Up
- View Leaderboards

Administrators can

- Manage Users
- Approve Community Quests
- Remove Posts
- Moderate Content
